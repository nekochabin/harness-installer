限定配布・試用版

選ぶだけで、いつもの仕事を「次も同じ品質で回せる型」にする

Claude と Codex に取り込む「スキル」です。一度入れれば、長い指示文を毎回貼る必要はありません。

これで何が起きるか

任せたい仕事を一言→選択式の質問に答える→流れの図を見て「はい」→AIが手順・採点表・テストを作って試す→完成

あなたがするのは「選ぶ」「資料を置く」「はい／いいえ」だけです。送信・公開・削除など取り消しにくい操作の前では、必ず止まって確認します。

1. ファイルを受け取る

Claude 用スキルをダウンロード（zip）

zip は解凍せず、そのまま次へ。

2. Claude に取り込む（最初の1回だけ）

  1. Claude（ブラウザ版かデスクトップアプリ）を開く
  2. 左下の名前 →「設定」または「カスタマイズ」→「スキル」を開く
  3. 「＋」または「アップロード」で、さっきの zip を選ぶ。スイッチがオンになっていれば完了

「コード実行とファイル作成」がオフだと動きません。設定の「機能」でオンにしてください。プランによっては表示されない場合があります。

Claude Code を使っている人はこちら

zip を解凍し、出てきた「harness-installer」フォルダを、使いたいプロジェクトの .claude/skills/ に置いてください。ホームの ~/.claude/skills/ に置くと、どこでも使えます。Claude Code で使うと、パソコン上に作業フォルダまで作ってくれます。

1. Codex に取り込む（最初の1回だけ）

ChatGPT アプリの Codex（または Codex CLI）で、次の一文をそのまま送ってください。

$skill-installer https://github.com/nekochabin/harness-installer/tree/main/codex/harness-installer をインストールして

「保存してよいか」の確認が出たら、許可してください。終わったら Codex を開き直します。

手で入れたい人はこちら

Codex 用 zip を解凍し、「harness-installer」フォルダをホームの ~/.agents/skills/（そのフォルダだけで使うなら、作業フォルダの .agents/skills/）に置いてください。

2. 作業するフォルダを開く

Codex で、この仕事用のフォルダを選んでおくと、その中に手順書一式を作ります。ホームやデスクトップ全体は選ばないでください。

3. 話しかける

新しいチャット（Codex なら新しいスレッド）で、こう言うだけです。

いつもの仕事を型にしたい

「毎週の報告書づくりをAIに任せたい」のように、仕事の名前を入れるともっと早く進みます。

使ってみたら、感想をください

試用版です。「ここで止まった」「この質問が分かりにくかった」など、一言で十分です。作者（ホロ）まで直接どうぞ。
